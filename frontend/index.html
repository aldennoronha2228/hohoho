Wireup — Local Circuit & Microcontroller Simulator

Editor · Examples · About & Licenses

Write firmware, wire components, and run circuit simulations locally. Wireup builds on Velxio's multi-board workspace with AVR8 and RP2040 emulation, backend-supported targets, SPICE analog simulation, Monaco Editor, and the arduino-cli compiler.

The open-source build needs no account. Export projects as .vlx files and import Wokwi bundles. Compilation requires the local backend and the selected board's toolchain.
